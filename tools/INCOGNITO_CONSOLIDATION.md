# Инкогнито Brain Desk в консолидации памяти

Brain Desk передаёт метку `BRAIN_DESK_INCOGNITO_V1` в системном сообщении
инкогнито-чата. Мост и граф всё ещё создают облачный тред для ответа. Читатель
недавних разговоров `native_recent_conversations` перед составлением выжимки
пропускает весь тред, если метка встретилась в **любом** сообщении, включая
системное, инструментальное и сообщения вне последних 12 показываемых реплик.

Плановая консолидация не получает текст такого треда для записи карточек
`/memories/`. Это правило не удаляет уже существующие облачные треды и не
заменяет ограничения хранения у провайдера. Проверка работает для тредов,
которые читает `native_recent_conversations` в текущем окне поиска.

Регрессия без модели и сети: `uv run --frozen python -m pytest -q
tests/test_incognito_consolidation.py`; отдельный CI job выполняет её и Ruff.
После слияния нужен деплой графа владельцем и проверка реального инкогнито-чата
в установленном окне без записи в память.
